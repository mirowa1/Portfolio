Selected work

Two course projects with live demos, evaluation, and measurable outcomes.

CIS 8045 · Agentic AI

SupportBot

Multi-agent customer support for e-commerce. A four-agent pipeline — Router → Retriever (FAISS RAG) → Generator → Critic — drafts grounded replies on Olist order data and escalates when it cannot answer safely.

  • LangChain · GPT-3.5 · FAISS · MiniLM · Gradio · LangSmith
  • Pilot eval (n=15): 100% task success · HHH 3.20 / 4.27 / 5.00 · 53.3% escalation
  • Documented failure mode (R1): missing order ID can hallucinate details

Stack: Python, LangChain, OpenAI, FAISS, Gradio

CIS 8040 · Data Management

SmartRoute

Traffic-aware route recommendation for event days. MySQL stores road segments and speeds; congestion is flagged when average speed drops below half the limit. Compares driver options and recommends the clearer path.

  • World Cup demo: Maxwell → Mercedes-Benz Stadium
  • Northside Dr congested (12.5 / 35 mph) · Marietta St clear
  • Recommendation: Option B — 18 min vs 28 min on the jammed path
  • NL→SQL tool: ask in English, get SELECT-only answers from the same DB

Stack: Python, MySQL, OpenAI (NL→SQL)
