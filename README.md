# Maxwell Irowa — Portfolio

GitHub Pages site featuring:

- **Coursework by CoreMax** — student productivity SaaS ([coremaxsystems.com](https://www.coremaxsystems.com))
- **SupportBot** — multi-agent e-commerce support (CIS 8045)
- **SmartRoute** — MySQL + NL→SQL traffic routing (CIS 8040)

## Live URL

After Pages is enabled:

**https://mirowa1.github.io/Portfolio/**

## Local preview

Open `index.html` in a browser, or:

```bash
cd Portfolio
python3 -m http.server 8080
```

Then visit http://127.0.0.1:8080
